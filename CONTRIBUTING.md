Contributing to the Bioinformatics Learning Roadmap

Thank you for your interest in contributing to this repository!

The goal of this project is to help people learn bioinformatics for free, from beginner-level programming to advanced topics such as RNA-seq analysis, genomics, transcriptomics, and single-cell analysis.

Everyone is welcome to contribute by suggesting learning resources, correcting mistakes, reporting broken links, or improving the learning roadmap.

What Can You Contribute?

You can contribute by:

- Suggesting free bioinformatics courses and tutorials.
- Recommending English-language YouTube playlists.
- Adding practical exercises and hands-on projects.
- Suggesting high-quality resources for Python, R, Linux, statistics, and data analysis.
- Recommending RNA-seq, genomics, transcriptomics, and single-cell analysis tutorials.
- Reporting broken or outdated links.
- Correcting technical errors and improving explanations.
- Suggesting improvements to the learning order.

Guidelines for Adding Resources

Please make sure that suggested resources meet the following guidelines:

1. The resource should be free to access.
2. The resource should be relevant to bioinformatics or a related subject.
3. The link should lead directly to the course, tutorial, playlist, or documentation.
4. Resources should be organized according to their appropriate difficulty level: beginner, intermediate, or advanced.
5. Practical tutorials, exercises, and real-world examples are especially encouraged.
6. YouTube playlists should be taught in English.
7. Please check whether the resource already exists in the repository before adding it.
8. Prefer reliable, high-quality resources from universities, research institutions, recognized educators, and established scientific projects.

If a resource requires payment for essential content, please do not submit it as a free resource.

How to Contribute

Option 1: Open an Issue

If you want to suggest a resource, report a broken link, or recommend an improvement, open an issue in the GitHub repository.

Please include:

- The resource name.
- The direct URL.
- The topic it covers.
- The recommended difficulty level.
- A short explanation of why it is useful.
- Confirmation that the resource is free to access.

Option 2: Submit a Pull Request

If you want to make changes directly:

1. Fork this repository.
2. Create a branch for your changes.
3. Edit the relevant Markdown file.
4. Check that your links work correctly.
5. Submit a pull request explaining your changes.

Small corrections, such as fixing spelling mistakes or updating broken links, are also welcome.

Suggested Format for Resources

Please use a format similar to this when adding a resource:

- "Resource Name" (https://example.com) — A short description of what the resource teaches. Level: Beginner. Cost: Free.

Replace the example URL with the actual resource link.

Keep the Roadmap Organized

Please add each resource to the most relevant section of the repository.

Try to maintain a clear learning progression from fundamentals to advanced topics. Avoid adding duplicate resources unless they offer a meaningful alternative.

For technical tutorials, please mention important prerequisites when relevant.

Community Guidelines

- Be respectful and constructive.
- Explain your suggestions clearly.
- Check facts and links before submitting changes.
- Do not copy copyrighted course materials without permission.
- Link to original resources and respect their licenses.
- Do not submit misleading, unsafe, or irrelevant content.
